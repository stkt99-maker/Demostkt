# คู่มือการใช้งาน Zabbix PDF Report

ต่อจาก [คู่มือติดตั้ง](INSTALL.md) — เอกสารนี้อธิบายวิธีใช้งานทุกฟีเจอร์ของรุ่นนี้ ตั้งแต่ล็อกอิน การเลือกข้อมูล การอ่านหน้าสรุปท้ายรายงาน จนถึงหน้าตั้งค่าโลโก้และข้อความ

## เข้าสู่ระบบ

เปิด `http://<ip-zabbix>/zabbix-pdf-report/login.php` แล้วล็อกอินด้วยบัญชี Zabbix ของคุณเอง (บัญชี API ที่ตั้งไว้ใน `config.php` ใช้ตอนสร้างรายงาน ไม่เกี่ยวกับบัญชีที่ใช้ล็อกอิน)

- **เปลี่ยนภาษา** — ลิงก์ TH / EN / ES มุมซ้ายบน ครอบคลุมทั้งหน้าเว็บและข้อความใน PDF
- **สลับธีม** — ปุ่มมุมขวาบน สลับธีมมืด/สว่าง ตั้งต้นตามค่าที่ระบบของคุณใช้อยู่
- **ออกจากระบบ** — ปุ่ม ⎋ ออกจากระบบ มุมขวาบนของหน้าฟอร์มและหน้าตั้งค่า กดแล้วระบบลบเซสชันและ cookie ฝั่งเซิร์ฟเวอร์ทิ้ง

พอล็อกอินผ่าน ระบบก็พาเข้าหน้า "ส่งออกรายงาน PDF Zabbix" ทันที ถ้ากรอกผิดซ้ำ ๆ Zabbix จะบล็อกชั่วคราวราวหนึ่งนาที ข้อความจะขึ้นว่า "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" แม้คุณพิมพ์ถูกก็ตาม รอสักครู่แล้วลองใหม่ รุ่นนี้ลองใหม่เองหนึ่งครั้งก่อนรายงานความผิดพลาดให้ด้วย

## เลือกข้อมูลที่จะทำรายงาน

เลือกได้สามทาง ใช้ร่วมกันก็ได้ ทุกช่องพิมพ์แก้เองได้ (คั่นด้วยเครื่องหมายจุลภาคหรือขึ้นบรรทัดใหม่)

### Hosts

พิมพ์ชื่อ host ตรง ๆ หรือกดปุ่ม **เลือก** เปิด modal ค้นหาจากรายชื่อทั้งหมด มีช่องกรองและปุ่มเลือกทั้งหมด/ล้างให้ พอกดยืนยัน ระบบจะ**เติมข้อมูลให้อัตโนมัติ**: กลุ่ม host ของเครื่องนั้น และรายการ item ที่เปิดใช้งานทั้งหมด ไหลเข้าช่องด้านล่างทันที — เอาไว้ลดงานพิมพ์มือ ชุดใหม่จาก host ที่ยืนยันล่าสุดจะทับรายการเดิมที่เคยเลือกไว้

### กลุ่ม Host (Host groups)

กดปุ่ม **เลือก** แล้วเลือกทั้งกลุ่ม ระบบดึงทุก host ในกลุ่มมาเป็นชุดรายงานเอง เหมาะกับงานรายงานรายทีมหรือรายแพลตฟอร์ม

### เทมเพลตและ Items

- **ช่องเทมเพลต (Templates)** — กดปุ่ม **เลือก** ไปหยิบเทมเพลต เช่น Template OS Linux แล้วเลือก item ที่ต้องการจากเทมเพลตนั้น ระบบค้นหา item ที่ key ตรงกันบนทุก host ที่เลือก รองรับ key ที่มีเครื่องหมายจุลภาคในตัว เช่น `perf_counter_en["\PhysicalDisk(...)",60]`
- **แผง "Items ที่จะทำในรายงาน"** — แผงรายการบนหน้าฟอร์ม แสดง item ปัจจุบันทั้งหมดที่จะลงรายงาน ติ๊กเลือก/ถอดออกได้ทันที มีช่องค้นหา ปุ่มเลือกทั้งหมด/ล้างทั้งหมด และตัวนับจำนวน ถ้าแผงว่าง ข้อความจะนำทางว่าให้เลือก Hosts ก่อนหรือกดปุ่มเลือกจากเทมเพลตด้านบน

กติกาของแผงนี้เรียบง่าย: สิ่งที่ติ๊กอยู่ตอนกดสร้าง PDF คือสิ่งที่ลงรายงาน ถอดติ๊กแล้วถอดออกจากรายงานทันที ส่วนรายการที่ช่องค้นหากรองซ่อนไว้ สถานะเดิมยังอยู่ครบ ไม่หายไปไหน

## กำหนดช่วงเวลา

- **ปุ่มลัด** — 1 วันล่าสุด / 1 สัปดาห์ล่าสุด / 1 เดือนล่าสุด / 1 ปีล่าสุด กดแล้วเติมช่อง จาก: ถึง: ให้เอง
- **ระบุเอง** — เลือกวันเวลาตรง ๆ ทั้งสองช่อง ระบบแปลงจากเขตเวลาที่เบราว์เซอร์ของคุณใช้ ไปเป็นเขตเวลาของ Zabbix ให้เอง
- **ไม่ระบุ** — ใช้ช่วง 24 ชั่วโมงล่าสุด

## สร้าง PDF

กดปุ่ม **สร้าง PDF** เบราว์เซอร์จะเปิดแท็บใหม่แล้วดาวน์โหลดไฟล์ทันที ชื่อไฟล์รูปแบบ `zabbix_report_YYYYMMDD_HHMMSS.pdf` รายการยิ่งเยอะไฟล์ยิ่งใหญ่และใช้เวลายิ่งนาน — host ที่มี item หลักร้อยรายการ ควรคัดเฉพาะที่จำเป็นก่อนสร้าง

## โครงสร้างไฟล์ PDF ที่ได้

| ส่วน | รายละเอียด |
|---|---|
| หัวกระดาษ | โลโก้องค์กร (ตั้งได้ในหน้าตั้งค่า) กับชื่อบริษัท |
| สารบัญ | รายชื่อกราฟทุกหน้า พร้อมเลขหน้า คลิกชื่อเพื่อกระโดดไปหน้านั้น |
| กราฟ | หนึ่ง item ต่อหนึ่งกราฟต่อหนึ่ง host ขนาด 1600×400 พร้อมหัวเรื่องชื่อ host |
| สรุปและวิเคราะห์ข้อมูล | หน้าใหม่ท้ายเล่ม อ่านรายละเอียดด้านล่าง |
| ท้ายกระดาษ | วันเวลาที่สร้าง เลขหน้า และเครดิต |

### หน้า "สรุปและวิเคราะห์ข้อมูล"

สร้างให้อัตโนมัติจากข้อมูลจริงของช่วงเวลาที่เลือก ประกอบด้วย

1. **ภาพรวม** — ครอบคลุมกี่โฮสต์ กี่รายการ ช่วงเวลาอะไร
2. **ตารางสถิติราย item** — ต่ำสุด / เฉลี่ย / สูงสุด / ล่าสุด / แนวโน้ม ระบบจัดรูปหน่วยให้ตามชนิด item อัตโนมัติ เช่น %, B/Bps, bps, วินาที (โชว์เป็น d/h/min), uptime (โชว์เป็น 18d 8h), unixtime
3. **ข้อสังเกต** — ย่อหน้าอ่านง่ายสำหรับผู้บริหาร เช่น "CPU: … เฉลี่ย 88.1% (สูงสุด 99.2%) — โหลดสูงกว่าเกณฑ์ 80%" พร้อมบรรทัดรายการที่มีค่าเฉลี่ยสูงสุด 3 อันดับแรก ถ้าไม่มีอะไรเกินเกณฑ์ก็ขึ้นว่าระบบทำงานปกติ

เกณฑ์แจ้งเตือนตายตัวของรุ่นนี้: CPU เฉลี่ย ≥ 80%, หน่วยความจำ ≥ 85%, พื้นที่ดิสก์ ≥ 90% ส่วน**แนวโน้ม**เทียบค่าเฉลี่ยครึ่งแรกกับครึ่งหลังของช่วงเวลา ต่างกันเกิน 5% ถึงจะขึ้นว่าเพิ่มขึ้น/ลดลง

รายการที่ไม่ขึ้นในตาราง: item ตัวเลขที่ไม่มีข้อมูลในช่วงเวลานั้น หรือ item ชนิดข้อความ (ไม่มีสถิติให้สรุป) — กราฟของ item เหล่านั้นยังอยู่ครบในเล่มตามปกติ

## หน้าตั้งค่า

เปิดที่ `settings.php` (หรือเมนูตั้งค่าจากหน้าฟอร์ม) แก้สามหมวด:

- **ข้อความหน้าฟอร์ม** — หัวข้อหน้า ป้ายช่องกรอก ตัวอย่าง placeholder ข้อความท้ายหน้า
- **ข้อความใน PDF** — ชื่อบริษัทบนหัวกระดาษ หัวข้อสารบัญ ข้อความท้ายกระดาษ
- **โลโก้** — อัปโหลดรูป PNG/JPG ขององค์กร ขึ้นทั้งหัวกระดาษ PDF และหน้าล็อกอิน

ทุกค่าเก็บที่ `data/settings.json` มีผลกับทุกภาษาทันที ไม่ต้องแก้โค้ดหรือไฟล์ภาษา

## ปัญหาที่พบตอนใช้งาน

| อาการ | วิธีจัดการ |
|---|---|
| กดสร้าง PDF แล้วขึ้น `token CSRF incorrecto` | กด F5 reload หน้าฟอร์มหนึ่งครั้ง แล้วใช้ต่อได้ปกติ |
| ล็อกอินแล้วขึ้น "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" ทั้งที่พิมพ์ถูก | Zabbix บล็อกชั่วคราวจากการลองซ้ำ รอราวหนึ่งนาทีแล้วลองใหม่ |
| กราฟหายไปบางรายการ | item นั้นไม่มีข้อมูลในช่วงเวลา หรือไม่มีอยู่บน host นั้น ดูรายละเอียดใน [INSTALL.md ปัญหาที่พบบ่อย](INSTALL.md) |
| ตารางสรุปท้ายเล่มไม่มีรายการ | ส่วนใหญ่เพราะ item ทุกตัวเป็นชนิดข้อความ หรือไม่มีข้อมูลในช่วงเวลาที่เลือก |
| PDF ใหญ่/ช้ามาก | ลดจำนวน item ผ่านแผง "Items ที่จะทำในรายงาน" ก่อนสร้าง |

ปัญหาตอนติดตั้ง (extension ขาด สิทธิ์โฟลเดอร์ ฯลฯ) ดูที่ [คู่มือติดตั้ง](INSTALL.md)
